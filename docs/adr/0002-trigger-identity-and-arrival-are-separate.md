# ADR 0002：触发、帧身份与到达时刻分离

- 状态：已接受
- 日期：2026-10-22

## 决策

GPIO 上升沿定义曝光触发事件，FrameSpecInfo `FrameCounter` 定义 payload 身份，两侧主机接收时间只定义 USB/SDK 到达事件。双目配对只能依赖 FrameCounter，不依赖线程回调顺序或到达时间。

## 原因

同一触发的两幅图像会因 USB 调度、控制器、SDK 队列和线程调度而乱序到达。到达更早不代表曝光更早。现有相机上的 `ExtTriggerCount` 还出现过 0/+2 步进，因此不能单独充当身份键。

## 后果

每帧需要记录更多时间戳和计数器，并维护有界对齐队列；换来的是传输乱序不会污染立体几何，同时仍能统计真实传输延迟。
