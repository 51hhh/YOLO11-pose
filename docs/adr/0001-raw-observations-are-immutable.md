# ADR 0001：原始观测不可变

- 状态：已接受
- 日期：2026-10-22

## 决策

`trajectory.csv` 只保存由左右图像直接三角化得到的球心观测及测量协方差。滤波、平滑、补点、轨迹预测、等效旋转、动力学参数与 RL 特征必须写入以输入哈希和配置指纹命名的 `derived/` 目录，永不回写原 trial。

## 原因

视觉误差和动力学残差必须能分别估计。若滤波状态覆盖测量，后续无法判断误差来自检测、双目几何、时钟还是物理模型，也无法用新算法重放同一份事实。

## 后果

存储量会增加，消费者必须明确选择原始或派生层；换来的是可审计、可重算和可比较的数据闭环。
