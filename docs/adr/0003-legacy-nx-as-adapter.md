# ADR 0003：旧 NX 工程作为过渡适配器

- 状态：已接受
- 日期：2026-10-22

## 决策

保留 `adapters/legacy_nx` 的实机能力，但从根工程以隔离 ExternalProject 构建，并由主线配置生成器和 CLI 驱动。新 core、ports、algorithms 和 services 不得依赖其头文件或全局状态。

## 原因

一次性重写相机、GPU 推理、CUDA 双目和 ROS2 会引入无法同时定位的硬件风险；继续把旧目录当作全部主线又会维持不清晰边界和重复配置。

## 后果

过渡期存在两套构建边界和一个配置投影层。每迁出一个功能都必须用同一录制输入进行等价性和性能回归，最终才能删除适配器。
